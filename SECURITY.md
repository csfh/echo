# Security policy

## Supported versions

Echo is early-stage software. Security fixes are applied on the default branch
(`main`) as needed. There is no long-term support window for older tags yet.

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Email **[oss@christofferhallas.com](mailto:oss@christofferhallas.com)** with:

- a description of the issue and its impact;
- steps to reproduce, or a proof of concept if available;
- affected versions, commits, or platforms if known.

We will acknowledge receipt when we can and work with you on coordinated
disclosure. Please give us a reasonable window to investigate and ship a fix
before public discussion.

For non-security bugs, use GitHub issues.
